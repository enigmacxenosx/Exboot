# Changelog

## 0.4.2 — Splash startup compatibility

Exboot keeps the ENOSX AI-inspired splash experience during normal startup while bypassing the visual splash during the automated smoke-test mode. This allows the Windows release workflow to validate the installed executable without waiting on a separate splash window.

## 0.4.1 — ENOSX splash experience

Exboot added the ENOSX AI-inspired startup splash with an animated cyan glow, EX mark, Enosx Technologies branding, and loading progress bar. The installer version was updated to 0.4.1 while the existing USB safety workflow and update verification behavior remained unchanged.
